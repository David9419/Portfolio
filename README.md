# David Baron — Portfolio

> Des idées aux projets concrets.

Portfolio personnel de David Baron, créateur digital & entrepreneur.

## Technologies
- **Next.js 16** (App Router, TypeScript)
- **Tailwind CSS v4** — couleurs de la charte dans `src/app/globals.css`
- **Motion** — animations (apparitions, effet aimant, cartes 3D, parallaxe)
- **next-themes** — mode sombre / mode clair
- Polices : **Montserrat** (titres), **Inter** (textes), **Allura** (signature)

## Modifier un texte
Tous les textes sont dans **`src/lib/contenu.ts`** (projets, compétences, parcours, contact…).

## Lancer en local
```bash
npm install
npm run dev
```
Puis ouvrir http://localhost:3000

## Mise en ligne
Hébergé sur **Vercel** : chaque envoi sur `main` met le site à jour automatiquement.
